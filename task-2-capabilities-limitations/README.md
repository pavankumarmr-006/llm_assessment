
# Task 2 - Capabilities and Limitations Lab

## Objective
To test the capabilities and limitations of Large Language Models (LLMs).

## Tools Used
- ChatGPT
- VS Code
- Git
- GitHub

## 1. Basic Capability Tests

Tested the following five capabilities:

1. Summarisation
2. Classification
3. Information Extraction
4. Translation
5. Code Generation

## 2. Knowledge Cutoff Test

Tested the model using a recent technology announcement.

Compared the answer with an official source to check whether the model knew the latest information.

## 3. Hallucination Test

Used a fictional research paper to test whether the model generates false information.

Repeated the test with the instruction to say "I don't know" if unsure.

## 4. Context Length Test

Placed a project code in the middle of a company report.

Expected project code: BLUE-7429.

Checked whether the model could retrieve the correct information.

## 5. Arithmetic Reasoning Test

Tested a shop bill calculation involving discount and tax.

Verified final amount: Rs. 159.30.

## 6. Logic Puzzle

Tested a production problem involving 100 machines.

Verified answer: 1 minute.

## 7. Five Business Application Safeguards

1. Input validation.
2. Human verification.
3. Hallucination prevention.
4. Data privacy.
5. Output validation.

## Conclusion

LLMs can perform many useful tasks, including summarisation, classification, translation and code generation.

However, they can produce hallucinations, miss recent information and make arithmetic or logical reasoning mistakes.

Therefore, businesses should implement safeguards and verify important AI-generated outputs.
